# Bundled BRFSS inputs

The full application package includes the four original CDC public survey archives supplied for this project. Their contents were preserved byte for byte. The filenames omit browser download suffixes such as `(1)`.

| File | Contents |
|---|---|
| `LLCP2023XPT.zip` | 2023 survey in SAS Transport format |
| `LLCP2024XPT.zip` | 2024 survey in SAS Transport format |
| `codebook23_llcp-v2-508.zip` | 2023 BRFSS survey codebook |
| `codebook24_llcp-v2-508.zip` | 2024 BRFSS survey codebook |

See [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json) for SHA-256 hashes and archive contents. Source pages: [CDC BRFSS 2023](https://www.cdc.gov/brfss/annual_data/annual_2023.html), [CDC BRFSS 2024](https://www.cdc.gov/brfss/annual_data/annual_2024.html), and [CDC agency materials guidance](https://www.cdc.gov/other/agencymaterials.html).

These survey records are used for migration parity. The claims workflow uses separately bundled synthetic records.
